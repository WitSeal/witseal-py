# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its Code of
Conduct. The full, canonical text is published here:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project you agree to uphold it.

## Our standards

Be respectful, assume good faith, and keep discussion focused on the
technical work. Harassment, personal attacks, and discriminatory behavior
are not tolerated, in project spaces and in public spaces when representing
the project.

## Enforcement

Report unacceptable behavior to **conduct@witseal.com**. Reports are
reviewed and investigated promptly and fairly; the reporter's privacy is
respected. Maintainers apply the Contributor Covenant 2.1 enforcement
guidelines (correction → warning → temporary ban → permanent ban) in
proportion to the violation.
